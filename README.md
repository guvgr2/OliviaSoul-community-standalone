# 林离的信

**当前版本：1.0.0**

一个完全本机的写信程序。你写给她，她回给你；有时候她也会先写。

它**不是** OliviaSoul 的插件，也不依赖任何游戏本体 —— 这是从零起的一个独立程序。

---

## 它是什么

- **不联网也能用**：除了调用你自己填的模型接口生成回信，其余全在本机。
- **没有账号、不上传、不扣费**：信件和记忆都在这台机器上，一个 SQLite 文件里。
- **API Key 用 Windows DPAPI 按当前用户加密**：不写日志、不进任何导出包。换 Windows 用户或换机器后解不开，届时需要重新填一次（这是预期行为）。
- **界面是液态玻璃**：中性白柔光 + 半透明玻璃面 + 斜向反射带 + 微光晕 + 顶部高光。

## 怎么用

1. 装完启动，托盘里会出现图标，界面用 Edge 的应用窗口打开（没有地址栏，看起来就是一个程序）。
2. 第一次进 **设置 → 模型**，填接口地址和 API Key，点「测试连通性」。
3. 回 **信箱** 写第一句，寄出。等她回信。

## 关于「她先写」

这个功能**默认是关的**。打开之后，她只会在下面这些条件全部满足时写一封：

| 条件 | 默认值 |
|---|---|
| 可打扰时段 | 09:00 – 21:30 |
| 距上一封往来至少 | 20 小时 |
| 24 小时内最多 | 1 封 |
| 7 天内最多 | 3 封 |
| 上一封主动信必须已读 | 是 |
| 不能有其他信在生成中 | 是 |
| 至少要有一封已有往来 | 是 |

这些数字都能在设置里改。判定原则是**宁可不发** —— 任何一个条件不满足就跳过。

三条硬边界：

1. **不伪造用户发言。** 她先写的信没有任何「来信」，触发只来自程序这侧能观测到的事：你刚听完一首歌、整理时发现什么、你们有多久没往来、或者只是一个平常的下午。
2. **不推进关系。** 她先写的信不写新的情感、称呼或亲密动作。跨封账本只认她**已经发出的回信**，不认来信人的愿望、自称或单方面升级。
3. **不把设想当事实。** 记忆分两栏：「已成立的共同事实」和「未决」。你说「想学吉他」，它进的是未决，不会在几封信之后变成「你现在练得怎么样了」。

## 数据在哪

```
%APPDATA%\LinliLetters\letters.sqlite
```

卸载不会删这个目录 —— 你的信还在。想彻底清掉，连这个目录一起删。

## 目录结构

```
app/          本机服务与界面
  server.mjs      HTTP 服务、写信管线、主动来信、信件记忆
  secret-store.mjs  API Key 的 DPAPI 存取
  dpapi.ps1       DPAPI 加解密（经临时文件中转，不经命令行传参）
  public/         液态玻璃界面
  harness/        写信规则、人设、主动信规则与调性锚
src/LinliShell/ 外壳：托盘 + 拉起 Edge 应用窗口 + 退出时收干净 Node
runtime/node/   内置 Node 运行时（只带 node.exe）
```

## 打包

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1
```

需要 .NET 10 SDK 与 Inno Setup 6。产物是 `dist\` 下的安装程序。

## 说明

- 桌面快捷方式**直接指向 exe**，不经任何 .bat / .vbs / .ps1 中转 —— 中转脚本会被安全软件当成可疑启动项拦掉，图标点了没反应。
- 界面靠 `backdrop-filter` 做玻璃质感，所以必须有 Edge。没有 Edge 时会退回默认浏览器，功能一样，只是没有独立窗口。
- 生成回信要走你自己的模型接口，会产生费用，费用归你的接口账户，本程序不代收任何费用。
